# Моё портфолио

Мой сайт-визитка: немного обо мне, мои увлечения, учебные проекты и контакты.

[Открыть сайт](https://gorbuzova.github.io/personal-portfolio/)

## Что есть на сайте

- Главная с фотографией и коротким знакомством.
- Увлечения с комментариями, которые открываются при наведении или нажатии на карточку.
- Биография и несколько фактов об учёбе и спорте.
- Проекты со ссылками на репозитории и используемыми технологиями.
- Ссылки на GitHub, Telegram, ВКонтакте и почту.

Есть две темы оформления и меню для небольших экранов. Тему можно переключить кнопкой в шапке; после перезагрузки выбор сбрасывается.

## Как запустить

Достаточно открыть `index.html` в браузере. Стили, шрифты и изображения лежат в проекте, установка зависимостей не нужна.

Можно запустить локальный сервер из папки проекта:

```sh
python -m http.server 8000
```

Затем открыть [localhost:8000](http://localhost:8000). Сервер останавливается сочетанием Ctrl+C.

## Структура

```text
index.html                   — разделы, тексты и ссылки
assets/css/style.css         — оформление, темы и адаптивность
assets/css/bootstrap.min.css — сетка Bootstrap
assets/css/fonts.css         — подключение шрифтов
assets/fonts/                — шрифты и их лицензии
assets/images/               — фотография, иллюстрации, фоны и иконка сайта
```

## Технологии

HTML5, CSS3 и CSS-часть Bootstrap 5.3.3. Меню, переключатель темы и раскрытие комментариев работают на HTML и CSS. Для декоративных линий и анимаций используются SVG и CSS; настройка уменьшения движения учитывается.

Иллюстрации сгенерированы, фотография — моя. Шрифты подключены локально и распространяются по SIL Open Font License, Bootstrap — по MIT; файлы лицензий находятся рядом с ними.

JavaScript, сборка и серверная часть не используются. Тексты и ссылки редактируются в `index.html`, оформление — в `assets/css/style.css`. Сайт опубликован через GitHub Pages из корня ветки `main`.
