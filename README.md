# Мария Горбузова — персональный сайт

Локальный учебный сайт студентки второго курса программной инженерии СПбГУ. Текущая версия — переработка первой версии, а не новый проект. Сохранены пять разделов, тёплая палитра и HTML/CSS без JavaScript.

## Как посмотреть

Откройте `index.html` двойным щелчком. Все стили, шрифты и изображения хранятся локально, подключение к интернету для просмотра не требуется.

Для просмотра через статический сервер выполните из этой папки:

```sh
python -m http.server 8000
```

Откройте `http://localhost:8000`. Для остановки сервера нажмите Ctrl+C.

## Что изменилось в солнечной версии

- Вернулся солнечный editorial-стиль: кремовый фон, рассеянный янтарный и персиковый свет, мягкие серо-коричневые тени. Всё освещение расположено под фотографией. На фигуре нет декора, звёзд или линий.
- На главной показана вся видимая на исходном фото фигура и платье. Обрезки на поясе нет. Используется новый PNG «Портрет в сиреневом бальном платье.png», подготовленный пользователем. Файл скопирован без изменений (проверен SHA-256); повторная обработка фотографии не выполнялась. Нижний край растворяется с помощью CSS-маски и локального размытого слоя. Убран дополнительный разрыв перед увлечениями.
- Все **семь** картинок карточек созданы заново встроенным **image_gen**. Вырезки из референсов больше не используются. Спорт и гимнастика — мягкие силуэты без деталей лица; планета и пряжа — объёмные изображения на прозрачном фоне. Проекты оформлены атмосферной пиксельной сеткой, солнечными облаками и фрагментом кода, как по настроению в референсе.
- Промпты, режим генерации и полные пути семи файлов записаны в `assets/images/generation-prompts.json`. Генерация выполнялась отдельными запросами для каждого изображения. Все используемые файлы сохранены в проекте, а не подключены из внешнего каталога.
- Во всех разделах добавлены приглушённые фоновые мотивы, созданные image_gen: солнце, ладонь и свеча с огненным свечением. В «Обо мне» и контактах есть всего две маленькие белые звёздочки. Имя и фамилия одного цвета. Промпты фонов записаны в `assets/images/background-prompts.json`.
- Лишние слоганы не возвращались. Биографические факты и живые комментарии увлечений сохранены. JavaScript не добавлялся.

## Технологии и взаимодействие

- HTML5, CSS3, Bootstrap **5.3.3**, только CSS-часть фреймворка.
- CSS-переменные для темы; переключатель — нативный checkbox. Выбор не сохраняется после перезагрузки.
- Меню на узких экранах и личные комментарии — `details` / `summary`. Управление мышью, нажатием, Enter и пробелом. Для мыши доступно также раскрытие при наведении.
- Небольшие CSS transitions для кнопок и иллюстраций. Поддерживается `prefers-reduced-motion`.
- Нет JavaScript, обработчиков событий, системы сборки или серверной части.

## Файлы

```text
index.html                   — разделы, тексты, контакты
assets/css/style.css         — авторская тема и адаптивность
assets/css/bootstrap.min.css — Bootstrap 5.3.3
assets/css/fonts.css         — локальные подключения шрифтов
assets/fonts/                — шрифты и лицензии OFL
assets/images/maria-user-cutout.png — предоставленный пользователем PNG для главной
assets/images/background-*.webp — три мягких фоновых мотива
assets/images/background-prompts.json — промпты фоновых изображений
assets/images/*-generated.webp — семь изображений, созданных image_gen
assets/images/generation-prompts.json — промпты и пути сохранения
assets/images/star.svg — favicon
```

Bootstrap распространяется по MIT (`assets/css/bootstrap.LICENSE`); Cormorant Garamond, Manrope и Caveat — по SIL Open Font License (`assets/fonts/*-OFL.txt`). Фотография остаётся пользовательским материалом. Референсы использованы только как ориентир стиля и не включены фрагментами в новые изображения. Промежуточные изображения, веса моделей и Python-окружение не входят в сайт.

## Контакты для заполнения

В `index.html` оставлены два комментария `TODO` для Telegram и email. Пока адресов нет, блоки не являются ссылками. Для Telegram замените `div.contact-placeholder` на ссылку с настоящим адресом `https://t.me/…`; для почты используйте `mailto:…`.

Для приложения погоды публичная ссылка не указана. Для остальных проектов сохранены ссылки на `gorbuzova/convolution_rgb` и `gorbuzova/verihogg-lint`. C++ отмечен как язык, который только начинает изучаться.

## Проверка

Проверены широкая, планшетная и узкая компоновки в браузере, обе темы, мобильное меню, раскрытие комментариев нажатием и клавиатурой, загрузка изображений, локальные пути и якоря. В HTML нет `script`, `javascript:` или обработчиков событий; в файлах сайта нет `.js`. Альфа-канал предоставленного PNG сохранён без изменений. Совпадение цветов имени и фамилии проверено в браузере.

Проверка на физическом сенсорном устройстве не выполнялась. Для него используются стандартные нативные HTML-элементы.
