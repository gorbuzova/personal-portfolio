# Мария Горбузова — персональный сайт

Адаптивное учебное портфолио студентки второго курса программной инженерии СПбГУ. Тёплая светлая тема, дополнительная кофейная тема, настоящее фото с прозрачным фоном и авторские иллюстрации.

## Просмотр

Откройте `index.html` двойным щелчком. Интернет для отображения сайта не нужен: Bootstrap, шрифты и изображения находятся в папке `assets`.

По желанию запустите статический сервер из папки проекта:

```sh
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Технологии

- HTML5, CSS3, Bootstrap **5.3.3** (только CSS).
- CSS-переменные для двух цветовых тем, медиазапросы для адаптивности.
- Нативный checkbox для переключения темы. Выбор не сохраняется после перезагрузки.
- Нативные `details` / `summary` для мобильного меню и комментариев к увлечениям. Карточки открываются нажатием, Enter или пробелом. На устройствах с мышью предусмотрено также появление заметок при наведении.
- CSS transitions, transforms и keyframes, поддержка `prefers-reduced-motion`.
- JavaScript, JS-библиотек, сборки и серверной части **нет**.

## Структура

```text
index.html                  — все пять разделов
assets/css/style.css        — авторское оформление и адаптивность
assets/css/bootstrap.min.css— локальная копия Bootstrap
assets/css/fonts.css        — локальное подключение шрифтов
assets/fonts/               — Cormorant Garamond, Manrope, Caveat и лицензии OFL
assets/images/              — прозрачные фотографии и авторские SVG
.nojekyll                   — обычная статическая публикация на Pages
```

Разделы: главная, увлечения, обо мне, проекты, контакты. Навигация — якорные ссылки.

## Изображения и лицензии

`maria.webp` — фигура из предоставленного оригинала IMG_5589.JPG после локального удаления фона с помощью rembg / u2net_human_seg. RGB-содержимое исходной фотографии не перерисовывалось. Файл содержит настоящий альфа-канал. `maria-hero.webp` — кадрированная версия для главного экрана. Изменения: маска фона, кадрирование, уменьшение размера и сжатие WebP. Тонкие края волос обработаны автоматической маской; небольшая мягкость контура возможна.

Остальные изображения — оригинальные SVG, созданные для сайта: спортсменка, гимнастка, планета, пряжа, пиксельная свёртка, погода, линтер и звезда. Заимствованных стоковых иллюстраций нет. Сгенерированные лица не использовались. Встроенный редактор ImageGen оказался недоступен (HTTP 403); платный API не использовался.

Bootstrap распространяется по MIT (`assets/css/bootstrap.LICENSE`), шрифты — по SIL Open Font License (файлы `*-OFL.txt`). Фото относится к личным материалам Марии, его права не передаются.

## Что можно заполнить позже

В `index.html` найдите два комментария `TODO`: Telegram и email. Когда появятся настоящие адреса, замените соответствующие `div.contact-placeholder` на ссылки:

```html
<a href="https://t.me/ВАШ_ЛОГИН" target="_blank" rel="noopener noreferrer">
  <span>Telegram <span aria-hidden="true">↗</span></span>
  <small>@ВАШ_ЛОГИН</small>
</a>
```

Для почты аналогично используйте `href="mailto:ВАШ_АДРЕС"`. Сейчас выдуманных адресов и неработающих контактных ссылок нет.

У приложения погоды пока нет подтверждённого публичного репозитория. Когда он появится, замените подпись `.project-status` настоящей ссылкой. Для свёртки и линтера используются проверенные публичные репозитории `gorbuzova/convolution_rgb` и `gorbuzova/verihogg-lint`.

## Публикация на GitHub Pages

**Текущий статус: сайт подготовлен локально, на GitHub Pages не опубликован.** В окружении не найдена сохранённая авторизация GitHub; существующие репозитории не изменялись.

Самый простой путь без командной строки:

1. Войдите на [GitHub](https://github.com/login) в аккаунт `gorbuzova`.
2. Откройте [создание нового репозитория](https://github.com/new). Имя: `personal-portfolio`, видимость: **Public**. Создайте отдельный репозиторий.
3. На странице нового репозитория выберите **uploading an existing file** (либо **Add file → Upload files**).
4. Перетащите **содержимое** этой папки: `index.html`, `assets`, `README.md`, `.nojekyll`. Не загружайте внешний каталог `personal-portfolio` целиком: `index.html` должен оказаться в корне репозитория.
5. Нажмите **Commit changes**.
6. Откройте **Settings → Pages**. В **Build and deployment → Source** выберите **Deploy from a branch**. Укажите ветку **main**, папку **/ (root)**, нажмите **Save**.
7. Дождитесь завершения публикации во вкладке **Actions**. Адрес появится в **Settings → Pages**. При указанном имени он должен быть `https://gorbuzova.github.io/personal-portfolio/` — это ожидаемый адрес, а не подтверждение публикации.
8. Откройте опубликованный адрес и проверьте фото, все разделы, тёмную тему и карточки на телефоне.

Если предпочитаете Git, локальный репозиторий уже инициализирован. После создания пустого публичного репозитория и входа в GitHub выполните из этой папки:

```sh
git remote add origin https://github.com/gorbuzova/personal-portfolio.git
git push -u origin main
```

После этого включите Pages по пункту 6. Не используйте для сайта существующий репозиторий линтера.

## Проверка

Проверены широкая и мобильная компоновки в браузере, загрузка локальных изображений, отсутствие горизонтальной прокрутки, светлая и тёмная темы, раскрытие карточек мышью и клавиатурой, мобильное меню. Проверены локальные ссылки на файлы и якоря. В HTML отсутствуют `script`, обработчики событий и `javascript:`; файлов `.js` в сайте нет. Альфа-канал обеих фотографий содержит полностью прозрачные и непрозрачные пиксели.

На физическом сенсорном устройстве и в опубликованном GitHub Pages проверка пока не выполнена. Режим уменьшенного движения предусмотрен CSS-медиазапросом.
